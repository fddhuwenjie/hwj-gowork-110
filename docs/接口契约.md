# 接口契约（HTTP JSON）

- 基础路径：`/api/v1`；所有请求/响应均为 `application/json; charset=utf-8`。
- 时间：UTC RFC3339（如 `2026-08-23T02:00:00Z`）。
- 操作人：请求头 `X-Actor`（缺省 `system`），用于审计与双人复核判定。
- 分页：`?limit=1..100（默认 20）&cursor=<上一页 next_cursor>`，键集分页，按 `id` 升序稳定排序；
  响应 `{"items":[...],"next_cursor":"..."}`，无下一页时省略 `next_cursor`。
- 幂等：读数/目标排程/归档请求携带 `idempotency_key`，重复提交返回首次结果且 `replay=true`。
- 乐观锁：变更请求携带 `version`，失配返回 409 `version_conflict`。

## 统一错误

```json
{"error":{"code":"not_found","message":"instrument not found","details":{"id":7}}}
```

| HTTP | code | 含义 |
| --- | --- | --- |
| 400 | invalid_argument | 参数非法 |
| 401 | actor_required | 需要操作人 |
| 404 | not_found | 资源不存在 |
| 409 | conflict / version_conflict / invalid_transition / duplicate | 状态冲突、乐观锁失配、非法转换、唯一键冲突 |
| 412 | precondition_failed | 领域前置条件不满足（温度越界、校准未覆盖、序列跳号、迟到指标、复核人相同等） |
| 500 | internal | 内部错误 |

## 健康检查

- `GET /healthz` → `{"status":"ok","time":"..."}`

## 站点

- `POST /api/v1/sites` `{code,name,latitude,longitude,altitude_m}`
- `GET /api/v1/sites`（分页，支持 `status`）
- `GET /api/v1/sites/{id}`
- `PATCH /api/v1/sites/{id}` `{name?,latitude?,longitude?,altitude_m?,version}`
- `POST /api/v1/sites/{id}/decommission` `{version}`

## 仪器与通道

- `POST /api/v1/instruments` `{site_id,code,name,kind,temp_min_mK,temp_max_mK}`
- `GET /api/v1/instruments`（分页，支持 `site_id,status`）
- `GET /api/v1/instruments/{id}`；`GET /api/v1/instruments/{id}/history`（状态历史）
- `PATCH /api/v1/instruments/{id}` `{name?,kind?,temp_min_mK?,temp_max_mK?,version}`（窗口冻结期间拒绝）
- `POST /api/v1/instruments/{id}/maintenance` / `POST /api/v1/instruments/{id}/restore` `{version,reason?}`
- `POST /api/v1/instruments/{id}/channels` `{channel_no,name,wavelength_nm,gain,offset}`
- `GET /api/v1/instruments/{id}/channels`（分页）
- `PATCH /api/v1/channels/{id}` `{name?,gain?,offset?,status?,version}`（窗口冻结期间拒绝）

## 低温系统与预冷

- `POST /api/v1/instruments/{id}/cryo` `{name,target_temp_mK}`
- `GET /api/v1/cryo/{id}`；`GET /api/v1/cryo/{id}/sessions`；`GET /api/v1/cryo/{id}/readings`（分页）
- `POST /api/v1/cryo/{id}/precool` `{target_temp_mK,deadline_at}` → 创建预冷会话并排程超时作业；仪器 `registered/maintenance → precooling`
- `POST /api/v1/cryo/{id}/readings` `{temp_mK,pressure_mbar,recorded_at?,idempotency_key}`
  - 预冷中读数入区间 → 会话 stable、低温 stable、仪器 ready
  - 观测中读数越界 → 低温 abnormal、当前批次 isolated、登记异常（同一事务）

## 校准

- `POST /api/v1/instruments/{id}/calibration-plans` `{version_no,params,valid_from,valid_until}`
- `POST /api/v1/calibration-plans/{id}/approve` `{version}`
- `POST /api/v1/calibration-plans/{id}/activate` `{version}` → 启用并顶替旧 active 方案，排程到期作业
- `GET /api/v1/calibration-plans?instrument_id=`（分页）
- `POST /api/v1/sources` `{code,name,flux_jy,spectrum}`；`GET /api/v1/sources`
- `POST /api/v1/calibration-records` `{plan_id,source_id,result,deviation_pct,evidence_uri,performed_at}` → 不可变校准证据
- `GET /api/v1/calibration-records?instrument_id=`（分页）

## 观测窗口

- `POST /api/v1/windows` `{instrument_id,title,start_at,end_at}` → applied
- `POST /api/v1/windows/{id}/approve` `{version,plan_id}` → 冻结快照（仪器+通道+方案+目标优先级）
- `POST /api/v1/windows/{id}/activate` `{version}` → **事务：校准封存 + 观测启用**
  （方案 active→sealed，窗口→active，仪器→observing，校验低温 stable 与读数在区间，排程窗口结束作业）
- `POST /api/v1/windows/{id}/close` `{version}`；`POST /api/v1/windows/{id}/cancel` `{version}`
- `GET /api/v1/windows`（分页，支持 `instrument_id,status`）；`GET /api/v1/windows/{id}`（含冻结快照）

## 目标与曝光

- `POST /api/v1/windows/{id}/targets` `{name,ra_deg,dec_deg,priority,exposure_goal,idempotency_key}`
  （仅 applied 状态可排程，批准后优先级冻结）
- `GET /api/v1/targets/{id}`；`GET /api/v1/windows/{id}/targets`（分页）
- `POST /api/v1/targets/{id}/exposures` `{seq_no,duration_s,filter}` — `seq_no` 必须等于当前最大值 +1，否则 412
- `GET /api/v1/targets/{id}/exposures`（分页）

## 观测批次

- `POST /api/v1/windows/{id}/batches` `{target_id,object_uri,idempotency_key,retest_of_id?}`
  - 窗口必须 active；低温读数在区间；校准方案有效且存在合格校准记录
  - 目标最新批次为 isolated 时，必须携带 `retest_of_id` 指向该批次（关联复测）
- `POST /api/v1/batches/{id}/finish` `{version}` → frozen；校验校准有效期覆盖 `[started_at, finished_at]`
- `GET /api/v1/batches/{id}`；`GET /api/v1/windows/{id}/batches`（分页）

## 质量指标与异常

- `POST /api/v1/batches/{id}/metrics` `{snr,fwhm,background}` → 计算 score/passed，版本递增；
  批次已归档（迟到指标）或已有封存指标时拒绝
- `POST /api/v1/metrics/{id}/seal` → **事务：指标封存 + 异常复测**
  （不达标：批次→isolated、登记异常、创建关联复测批次、异常→retest_created）
- `GET /api/v1/batches/{id}/metrics`（分页）
- `POST /api/v1/batches/{id}/anomalies` `{kind,description}`（手工登记）
- `POST /api/v1/anomalies/{id}/resolve` `{version}`；`POST /api/v1/anomalies/{id}/close` `{version}`
- `GET /api/v1/anomalies`（分页，支持 `instrument_id,status`）

## 归档与发布

- `POST /api/v1/batches/{id}/archive` `{checksum_sha256,size_bytes,idempotency_key}` → pending（批次须 frozen），排程校验作业
- `GET /api/v1/archives/{id}`；`GET /api/v1/archives`（分页，支持 `status`）
- `DELETE /api/v1/archives/{id}` → 软删除（`deleted_at`）
- `POST /api/v1/archives/{id}/releases` `{title,expires_at}` → pending_review（归档须 verified）
- `POST /api/v1/releases/{id}/review` `{version,decision:approve|reject}` → 复核人必须 ≠ 提交人
- `POST /api/v1/archives/{id}/verify-and-publish` `{permit_id}` → **事务：归档校验 + 成果发布**
- `POST /api/v1/releases/{id}/revoke` `{version}`
- `GET /api/v1/releases/{id}`；`GET /api/v1/releases`（分页）

## 分析查询（稳定分页）

- `GET /api/v1/queries/instruments-pending-calibration?within_hours=72` — 临近窗口仍未完成校准的仪器
- `GET /api/v1/queries/cryo-anomaly-trend?days=7` — 低温异常趋势（按系统/日期聚合越界读数）
- `GET /api/v1/queries/target-conflicts` — 目标排程冲突（同仪器已批准/激活窗口时间重叠）
- `GET /api/v1/queries/quality-decline?min_consecutive=3` — 质量指标连续下降的批次链
- `GET /api/v1/queries/pending-retests` — 待复测（隔离且无完成复测）的批次
- `GET /api/v1/queries/expired-releases` — 已过期发布许可

## 后台作业

- `GET /api/v1/jobs`（分页，支持 `type,status`）；`GET /api/v1/jobs/{id}`
- `POST /api/v1/jobs/{id}/retry` → 将 failed/dead 作业重新排程
