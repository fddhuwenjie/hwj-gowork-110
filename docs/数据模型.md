# 数据模型

存储：嵌入式 SQLite（`database/sql` + `modernc.org/sqlite`），持久化到 `DB_PATH` 文件。
时间统一为 UTC RFC3339Nano 文本；温度为毫开尔文（REAL）；主键为自增整数。
所有可变实体携带 `version`（乐观锁）与 `created_at/updated_at`。

## 1. sites（站点）

| 列 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | |
| code | TEXT UNIQUE | 站点编码 |
| name | TEXT | 名称 |
| latitude / longitude | REAL | 纬度/经度（度） |
| altitude_m | REAL | 海拔（米） |
| status | TEXT | active / decommissioned |
| version | INTEGER | 乐观锁 |

## 2. instruments（观测仪器）

| 列 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | |
| site_id | INTEGER FK | 所属站点 |
| code | TEXT UNIQUE | 仪器编码 |
| name / kind | TEXT | 名称 / 类型 |
| status | TEXT | registered/precooling/ready/observing/maintenance/decommissioned |
| temp_min_mK / temp_max_mK | REAL | 有效温度区间 |
| version | INTEGER | 乐观锁 |

## 3. instrument_status_history（仪器状态历史，不可变）

id, instrument_id, from_status, to_status, reason, actor, created_at。只追加。

## 4. detector_channels（探测器通道）

id, instrument_id, channel_no（仪器内唯一）, name, wavelength_nm, gain, offset,
status(enabled/disabled), version。`UNIQUE(instrument_id, channel_no)`。

## 5. cryo_systems（低温系统）

id, instrument_id（唯一，一台仪器一套）, name, status(idle/precooling/stable/abnormal),
target_temp_mK, version。

## 6. precool_sessions（预冷会话）

id, cryo_system_id, status(precooling/stable/timeout/aborted), target_temp_mK,
started_at, deadline_at（预冷超时作业 run_at）, finished_at, version。

## 7. cryo_readings（温度读数，幂等，不可变）

id, cryo_system_id, temp_mK, pressure_mbar, recorded_at,
idempotency_key。`UNIQUE(cryo_system_id, idempotency_key)`。重复提交返回首次读数。

## 8. calibration_plans（校准方案版本）

id, instrument_id, version_no（仪器内唯一）, params(JSON), status(draft/approved/active/sealed/superseded/expired),
valid_from, valid_until, created_by, approved_by, version。`UNIQUE(instrument_id, version_no)`。

## 9. standard_sources（标准源）

id, code UNIQUE, name, flux_jy, spectrum, status(active/retired), version。

## 10. calibration_records（校准记录，不可变证据）

id, plan_id, source_id, instrument_id, result(pass/fail), deviation_pct,
evidence_uri, performed_by, performed_at, created_at。只追加，无更新入口。

## 11. observation_windows（观测窗口）

id, instrument_id, plan_id（冻结的校准方案）, title, start_at, end_at,
status(applied/approved/active/closed/cancelled),
frozen_snapshot（批准时的仪器/通道/方案/目标优先级 JSON 快照）,
applied_by, approved_by, version。

## 12. targets（目标计划，幂等）

id, window_id, name, ra_deg, dec_deg, priority, exposure_goal,
status(scheduled/acquiring/completed/cancelled), idempotency_key, version。
`UNIQUE(window_id, name)`，`UNIQUE(window_id, idempotency_key)`。

## 13. target_exposures（曝光序列，不可变）

id, target_id, seq_no（目标内严格连续）, duration_s, filter, created_at。
`UNIQUE(target_id, seq_no)`。

## 14. observation_batches（原始观测批次）

id, window_id, target_id, instrument_id, retest_of_id（复测关联，可空）,
object_uri, status(acquiring/frozen/isolated/archived),
started_at, finished_at, idempotency_key UNIQUE, version。

## 15. quality_metrics（质量指标）

id, batch_id, version_no（批次内递增）, snr, fwhm, background, score, passed,
sealed(0/1，封存后不可变), computed_by, computed_at, sealed_at。
`UNIQUE(batch_id, version_no)`。已归档批次拒绝新指标（迟到指标）。

## 16. anomalies（异常处置）

id, batch_id（可空）, instrument_id, kind(temp_out_of_range/precool_timeout/quality_below_threshold/calibration_expired/manual),
description, status(open/retest_created/resolved/closed), opened_by, resolved_by, created_at, updated_at。

## 17. archives（数据归档，幂等，软删除）

id, batch_id UNIQUE, object_uri, checksum_sha256, size_bytes,
status(pending/verified/failed/published), idempotency_key UNIQUE,
requested_by, verified_by, deleted_at（软删除）, version。不允许物理删除。

## 18. release_permits（发布许可）

id, archive_id, title, status(pending_review/approved/rejected/published/expired/revoked),
submitted_by, reviewed_by（必须 ≠ submitted_by）, submitted_at, reviewed_at,
published_at, expires_at, version。

## 19. audit_log（审计，不可变）

id, entity, entity_id, action, actor, detail(JSON), created_at。只追加。

## 20. jobs（后台作业，可重启恢复）

id, type(precool_timeout/calibration_expiry/window_end/archive_verify),
payload(JSON), status(pending/running/done/failed/dead),
attempts, max_attempts, run_at, last_error, created_at, updated_at。
`UNIQUE(type, payload)` 防止重复排程。

## 索引

- `cryo_readings(cryo_system_id, recorded_at)`：低温异常趋势
- `observation_windows(instrument_id, status, start_at)`：临近窗口/排程冲突
- `quality_metrics(batch_id, version_no)`、`observation_batches(target_id, id)`：质量连续下降分析
- `release_permits(status, expires_at)`：过期许可查询
- `jobs(status, run_at)`：作业认领
