# 状态转换表

所有状态转换由领域状态机统一校验（`internal/domain/transitions.go`），
非法转换返回 `invalid_transition`（HTTP 409）。下表 `→` 左侧为源状态，右侧为合法目标状态。

## 1. 站点 Site

| 源状态 | 目标状态 | 触发动作 |
| --- | --- | --- |
| active | decommissioned | 站点停用 |

## 2. 观测仪器 Instrument

| 源状态 | 目标状态 | 触发动作 |
| --- | --- | --- |
| registered | precooling | 开始预冷 |
| registered | maintenance / decommissioned | 维护 / 停用 |
| precooling | ready | 预冷会话转稳 |
| precooling | maintenance | 预冷超时（作业） |
| ready | observing | 窗口激活（事务） |
| ready | maintenance | 校准方案到期（作业）/ 人工维护 |
| observing | ready | 窗口结束（作业/人工） |
| maintenance | registered | 维护完成复位 |
| maintenance | decommissioned | 停用 |

每次转换追加 `instrument_status_history`（不可变）。

## 3. 探测器通道 DetectorChannel

| 源状态 | 目标状态 |
| --- | --- |
| enabled | disabled |
| disabled | enabled |

窗口批准/激活期间通道被快照冻结，任何变更被拒绝（非状态机转换）。

## 4. 低温系统 CryoSystem

| 源状态 | 目标状态 | 触发 |
| --- | --- | --- |
| idle | precooling | 开始预冷 |
| precooling | stable | 读数进入有效区间 |
| precooling | idle | 预冷超时（作业） |
| stable | abnormal | 越界读数 |
| stable | precooling | 重新预冷 |
| abnormal | precooling | 处置后重新预冷 |
| abnormal | idle | 人工复位 |

## 5. 预冷会话 PrecoolSession

| 源状态 | 目标状态 |
| --- | --- |
| precooling | stable（读数达标） |
| precooling | timeout（超时作业） |
| precooling | aborted（人工中止） |

## 6. 校准方案 CalibrationPlan

| 源状态 | 目标状态 | 触发 |
| --- | --- | --- |
| draft | approved | 审批 |
| approved | active | 启用（原 active 方案转 superseded） |
| active | sealed | 窗口激活事务（校准封存） |
| active | expired | 到期作业 |
| active | superseded | 新方案启用 |
| sealed | expired | 到期作业（窗口已结束后） |

| applied | cancelled | 撤销 |
| approved | active | 激活事务 |
| approved | cancelled | 撤销 |
| active | closed | 窗口结束（作业/人工） |

## 8. 目标计划 Target

## 9. 原始观测批次 ObservationBatch

| 源状态 | 目标状态 | 触发 |
| --- | --- | --- |
| acquiring | frozen | 批次结束（温度与校准覆盖校验通过） |
| acquiring | isolated | 越界温度读数 / 指标封存不达标 |
| frozen | isolated | 指标封存不达标 |
| frozen | archived | 归档校验通过 |
| isolated | （终态，仅允许创建关联复测批次） | — |

## 10. 质量指标 QualityMetric

| 源状态 | 目标状态 |

## 11. 异常 Anomaly

| 源状态 | 目标状态 |
| --- | --- |
| open | retest_created（复测批次已建） |

## 12. 数据归档 Archive

| 源状态 | 目标状态 | 触发 |
| --- | --- | --- |
| pending | verified | 校验作业 / 校验发布事务 |
| pending | failed | 校验不合格（批次未冻结、校验和缺失） |
| verified | published | 校验发布事务 |

软删除：`deleted_at` 置位后所有查询默认过滤；任何状态都不可物理删除。

## 13. 发布许可 ReleasePermit

| 源状态 | 目标状态 | 触发 |
| --- | --- | --- |
| pending_review | approved | 复核通过（复核人 ≠ 提交人） |
| pending_review | rejected | 复核驳回 |
| approved | published | 校验发布事务 |
| approved | expired | 超过 expires_at |
| published | revoked | 撤销 |
| published | expired | 超过 expires_at（查询口径） |

## 14. 后台作业 Job

| 源状态 | 目标状态 |
| --- | --- |
| pending | running（认领） |
| running | done（成功） |
| running | failed（失败，按退避重试） |
| failed | pending（重新排程，attempts < max_attempts） |
| failed | dead（attempts ≥ max_attempts） |
| running | pending（进程重启恢复） |
