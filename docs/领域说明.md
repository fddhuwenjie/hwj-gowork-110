# 领域说明：高纬度天文台低温仪器观测窗口与校准归档服务

## 1. 领域背景

高纬度天文台在极夜期间执行长波段巡天与定点观测。低温（致冷）仪器对工作温度极其敏感：
探测器只有在指定的毫开尔文（mK）温度窗口内才能产出满足科学质量要求的数据。
本服务负责管理从**站点建档**到**成果发布**的完整业务链，并对关键证据保留不可变历史。

## 2. 核心子域与职责

| 子域 | 职责 |
| --- | --- |
| 站点（Site） | 天文台地理站点建档、停用 |
| 观测仪器（Instrument） | 仪器建档、有效温度范围、状态机与状态历史 |
| 探测器通道（DetectorChannel） | 仪器下属通道的增益/偏置/波长配置 |
| 低温系统（CryoSystem） | 预冷会话、温度读数（幂等）、异常判定 |
| 校准方案版本（CalibrationPlan） | 方案草稿、审批、启用、封存、过期，版本唯一启用 |
| 标准源（StandardSource） | 定标标准源登记；校准记录为不可变证据 |
| 观测窗口（ObservationWindow） | 窗口申请、批准（冻结快照）、激活、结束 |
| 目标计划（Target） | 窗口内目标排程（幂等）、曝光序列（连续不跳号） |
| 原始观测批次（ObservationBatch） | 批次开始/结束、隔离、冻结、复测关联 |
| 质量指标（QualityMetric） | 指标计算、版本递增、封存（不可变） |
| 异常处置（Anomaly） | 温度异常、质量不达标等异常的登记与闭环 |
| 数据归档（Archive） | 批次冻结后的归档请求（幂等）、校验、软删除 |
| 发布许可（ReleasePermit） | 成果发布申请、双人复核、发布、过期、撤销 |
| 后台作业（Job） | 预冷超时、校准到期、窗口结束、归档校验、失败重试 |
| 审计（AuditLog） | 全部变更动作的追加式审计 |

## 3. 业务主链

```
站点建档 → 仪器建档 → 通道配置 → 低温系统登记
  → 校准方案(草稿→审批→启用) → 标准源校准(生成不可变校准记录)
  → 低温预冷(预冷会话, 读数进入有效区间后转稳)
  → 观测窗口申请 → 目标排程 → 窗口批准(冻结快照)
  → 窗口激活(事务: 校准封存 + 观测启用)
  → 观测执行(批次开始/结束, 校准覆盖与温度校验)
  → 质量指标计算与封存(事务: 指标封存 + 异常复测)
  → 数据冻结 → 归档请求(幂等) → 归档校验
  → 发布许可申请 → 不同人员复核 → 发布(事务: 归档校验 + 成果发布)
```

## 4. 关键不变量（领域规则）

1. **窗口冻结**：窗口批准时冻结仪器配置、探测器通道、校准方案与目标优先级快照；
   窗口处于已批准/已激活期间，仪器与通道的变更请求一律拒绝。
2. **温度有效**：预冷与观测全程，仪器温度读数必须落在 `[temp_min_mK, temp_max_mK]` 区间内；
   观测期间出现越界读数，低温系统转异常、当前批次隔离并登记异常。
3. **校准覆盖**：校准方案有效期 `[valid_from, valid_until]` 必须完整覆盖观测批次的
   `[started_at, finished_at]`，且必须存在该方案下结果合格的校准记录。
4. **曝光序列**：同一目标下曝光序号必须严格连续递增（`seq = max(seq)+1`），不得跳号、不得重复。
5. **质量隔离**：指标封存后若判定不达标，批次保持隔离状态，只能创建关联复测批次
   （`retest_of_id` 指向被隔离批次）。
6. **迟到指标**：批次一旦归档，拒绝写入任何新的质量指标，迟到指标不得覆盖已归档批次。
7. **双人复核**：发布许可的复核人（reviewed_by）必须与提交人（submitted_by）不同。
8. **幂等键**：低温读数、目标排程、归档请求使用幂等键去重，重复请求返回首次结果。
9. **乐观锁**：所有可变实体携带 `version`，更新必须匹配版本，失配返回 `version_conflict`。
10. **不可物理删除**：归档对象仅允许软删除（`deleted_at`），数据库不提供物理删除入口。
11. **不可变历史**：仪器状态历史、校准记录、已封存指标只追加、不修改。

## 5. 事务边界（真实 SQLite 事务，失败完整回滚）

| 事务 | 组成动作 |
| --- | --- |
| 校准封存与观测启用 | 窗口 applied/approved → active；校准方案 active → sealed；仪器 → observing；写状态历史与审计 |
| 指标封存与异常复测 | 指标 sealed=1；不达标时批次 → isolated、登记异常、创建关联复测批次；写审计 |
| 归档校验与成果发布 | 归档 pending → verified → published；许可 approved → published；写审计 |

## 6. 后台作业（可重启恢复）

| 作业类型 | 触发 | 动作 |
| --- | --- | --- |
| precool_timeout | 预冷会话创建时排程（run_at = 截止时间） | 超时仍未转稳：会话超时、仪器转维护、登记异常 |
| calibration_expiry | 方案启用时排程（run_at = valid_until） | 到期方案转 expired，无有效方案的仪器转维护 |
| window_end | 窗口激活时排程（run_at = end_at） | 到期窗口关闭，仪器转 ready，未完成批次自动冻结 |
| archive_verify | 归档请求时排程 | 待校验归档执行校验：合格转 verified，否则转 failed |

作业以 SQLite 表持久化，进程重启时将 `running` 恢复为 `pending` 重新认领；
失败作业按次数退避重试，超过最大次数进入 `dead` 状态。
